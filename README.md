# 마음쑥쑥 청소년상담사 3급

2020~2026년 기출 1,225문항을 담은 정적 웹 앱입니다. 선택과목을 적용하면 1,050문항을 학습합니다.

## 실행·배포

이 폴더에서 `python3 -m http.server 8000`으로 실행할 수 있습니다.
배포할 때는 ZIP 전체를 풀어 업로드하세요. `record-store.js`도 필요한 앱 파일입니다.
앱 설치와 오프라인 기능은 HTTPS 또는 로컬 개발 환경에서 동작합니다.

## 학습 기록과 복습

복습할 문제가 있으면 첫 화면의 첫 번째 메뉴는 ‘한번 더 보기’, 없으면 ‘오늘의 20문제’입니다.

- 학습 진도는 선택과목 범위에서 고유 문항 ID로 계산합니다.
- 일반 학습 결과의 정답률은 실제 응답한 문항의 첫 시도 정답 기준입니다. 재시도 포함 정답 수와 완료율도 별도로 표시합니다.
- 오답 복습은 틀린 날을 기준으로 1·3·7·14일 뒤 진행합니다. 첫 시도 정답이면 다음 단계로 넘어가고, 네 단계에 성공하면 완료합니다.
- 다시 틀리면 다음 날부터 새로 복습합니다. 늦게 복습한 경우 다음 단계는 최소 다음 날로 예약합니다.
- 기존 오답도 첫 단계부터 이어서 사용할 수 있으며, 선택하지 않은 과목의 기록은 보관하되 복습에는 출제하지 않습니다.
- 모의고사는 원문 선택지 순서를 유지합니다. 같은 응시 회차의 완료된 교시 결과는 새로고침 후에도 복원됩니다.
- 모의고사 풀이 중인 답과 타이머는 새로고침 시 복원하지 않습니다. 완료된 교시와 저장된 제출 기록이 복원 대상입니다.
- 새 1교시 또는 완료한 2교시 재응시는 새 회차로 시작하며, 기존 제출 기록은 유지합니다.

## 백업

첫 화면의 내보내기로 진도·오답·모의고사·선택과목·일일 출제 기록을 JSON 파일로 보관할 수 있습니다.
가져오기는 형식을 검증하고 확인을 받은 뒤 현재 기록을 백업 내용으로 교체합니다. 필요하면 먼저 현재 기록을 내보내세요.
읽을 수 없는 기록은 원본을 별도로 보존하고, 내보내기 파일의 `recovery` 항목에 포함합니다.
저장이 거부되거나 공간이 부족하면 알림이 표시됩니다. 이때 기록은 현재 창에서 유지되므로 창을 닫기 전에 내보내세요.

## 검증

Python의 Playwright와 Chromium이 있는 환경에서 `python3 tests/browser_checks.py`를 실행합니다.
검증은 임시 로컬 서버와 독립된 브라우저 프로필을 사용하며 사용자 학습 기록을 변경하지 않습니다.
